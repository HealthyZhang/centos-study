# 关机
> 格式： shutdown options time [message]
- options
	- -h 关闭所有服务后关机
	- -c 取消前一个关机计划
	- -r 重启
	- -f 重启时不检测磁盘
	- -k 并不真正关机，只是发送警告消息给所有用户
- shutdown
	- shutdown -h now //立刻马上关机
	- shutdown -h +10 //延迟10分钟后关机
	- shutdown -h 60 //60分钟（1个小时）后关闭
	- shutdown -h 3:00 //在3点关机
	- shutdown -k now "系统将在10分钟后关闭，请保存你的工作。"
	- shutdown -c //取消关机计划

# 重启
- shutdown -r now
- shutdown -r 60 //60分钟（1个小时）后重启
- shutdown -r 3:00 //在3点重启
